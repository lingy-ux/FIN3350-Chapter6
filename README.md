# FIN 3350 — Chapter 6 Practice Website

**Chapter 6: International Parity Conditions**  
Bilingual practice bank for *Fundamentals of Multinational Finance, 6e*.

## Open the website

After GitHub Pages is enabled, the public website will be available at:

https://lingy-ux.github.io/FIN3350-Chapter6/

## Contents

- 61 questions across Sections 6.1–6.4
- Multiple-choice, true/false, and essay questions
- English source wording with Chinese study support
- Section filtering and keyword search
- Individual answer checking and answer reveal
- Objective-question score and progress indicator
- English-only, Chinese-aid, and bilingual display modes

## Enable GitHub Pages (one-time setup)

1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The link above will then be shareable.

The website source is `index.html` in the repository root.
